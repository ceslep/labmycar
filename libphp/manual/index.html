Introducción al Sistema MyCar

Propósito del Sistema

El Sistema MyCar es una plataforma integral diseñada para la gestión de laboratorios clínicos, facilitando el registro de muestras, la consulta y publicación de resultados de exámenes de manera eficiente y segura. Orientado tanto a pacientes como a personal administrativo y de salud, busca optimizar los procesos de laboratorio y mejorar la comunicación de información vital.

Este manual proporciona una guía detallada para el uso de las diferentes funcionalidades del sistema, asegurando que los usuarios puedan aprovechar al máximo sus capacidades.

Acceso al Sistema

  • Acceso para Pacientes: Los pacientes pueden consultar sus resultados a través de una interfaz web pública, proporcionando sus datos de identificación para acceder a sus reportes de exámenes.
  • Acceso para Personal Administrativo/Clínico: El personal autorizado del laboratorio accede a un panel de gestión que permite buscar, filtrar, imprimir y compartir resultados de exámenes, así como gestionar información relacionada con entidades y pacientes. El acceso a este panel requiere una autenticación mediante contraseña.

Guía de Registro de Muestras

Interfaz de Registro de Muestras (mycar.iedeoccidente.com/web)

La interfaz en mycar.iedeoccidente.com/web es el punto de entrada para el registro inicial de muestras y datos de pacientes. Aquí, el personal de laboratorio ingresa la información necesaria a través de formularios dedicados, la cual será posteriormente gestionada y consultada en el sistema.

Aunque el detalle específico de cada campo de entrada y validación depende de la configuración de esta interfaz, el flujo general para el registro de una muestra y sus exámenes asociados implica:

  1. Ingreso de Datos del Paciente: Se capturan datos demográficos y de contacto del paciente.
  2. Asignación de Exámenes: Se seleccionan los exámenes solicitados para el paciente.
  3. Registro de la Muestra: Se asocia la muestra física con el paciente y los exámenes asignados.
  4. Generación de Órdenes: Se generan los documentos internos necesarios para el procesamiento de las muestras en el laboratorio.

Nota: El proceso exacto de "registro de muestras" y sus campos de entrada específicos se gestionan directamente en la URL mycar.iedeoccidente.com/web. Este manual se enfoca en la consulta y gestión de los resultados una vez que los datos han sido registrados en el sistema.

Consulta de Resultados para Pacientes

Acceso a la Consulta Pública

Los pacientes pueden acceder a sus resultados de laboratorio de manera sencilla y segura a través de la interfaz pública de consulta. La URL de acceso es: /paciente.html (o la ruta configurada para este archivo).

La interfaz principal consta de un formulario de consulta donde deberá ingresar su información personal para acceder a sus exámenes.

Página de consulta de resultados para pacientes

Pasos para Consultar Resultados

  1. Ingrese su Número de Identificación: En el campo "Ingrese el número de identificación", escriba su documento de identidad completo.
  2. Ingrese su Año de Nacimiento o Últimos Dígitos del Celular: En el campo "Ingrese el año de nacimiento", introduzca su año de nacimiento. Alternativamente, puede usar los últimos 4 dígitos de su número de teléfono celular registrado en el laboratorio.
  3. Haga Clic en "Consultar": Una vez introducidos los datos, presione el botón Consultar. El sistema procesará su solicitud y mostrará una lista de sus exámenes.
  4. Visualice sus Exámenes: Si sus datos son correctos, se mostrará una tabla con todos los exámenes asociados a su identificación y fecha. Cada fila contendrá el nombre del examen, la fecha de realización y un botón "Ver".
  5. Acceda al Reporte Detallado: Para ver el detalle de un examen específico, haga clic en el botón Ver junto al examen deseado. Esto abrirá el reporte completo en una nueva ventana o pestaña.

Gestión de Resultados para Personal Administrativo/Clínico

Acceso al Panel de Gestión (mycar.iedeoccidente.com/prt.php)

El panel de gestión es la herramienta principal para el personal del laboratorio. Para acceder, diríjase a /prt.php y complete el formulario de inicio de sesión.

Panel de gestión de resultados para personal administrativo

Una vez acceda a /prt.php, será dirigido directamente al panel principal de gestión de resultados si la sesión es válida. Este panel es la herramienta principal para el personal del laboratorio.

Panel Principal de Resultados

Una vez dentro, el panel principal le permite visualizar y gestionar los exámenes de los pacientes. La interfaz está dividida en una barra superior, un panel lateral de filtros/pacientes y un área principal para la visualización de reportes.

Vista general del panel administrativo con lista de pacientes y filtros

Barra Superior

Contiene el logo del laboratorio, el nombre del sistema, información del usuario autenticado y botones de acceso rápido a funcionalidades clave como ENTIDADES y PACIENTES, además del botón SALIR para cerrar sesión.

Panel Lateral (Filtros y Lista de Pacientes)

Este panel a la izquierda de la pantalla es donde puede buscar y seleccionar pacientes y sus exámenes.

  • Filtro por Fecha: Un campo de tipo fecha () permite seleccionar una fecha específica para ver los pacientes con exámenes registrados en ese día.
  • Campo de Búsqueda: Un campo de texto () para ingresar el número de identificación, nombres o apellidos del paciente para encontrarlo rápidamente.
  • "Buscar en todas las fechas": Una casilla de verificación () permite buscar sin restricciones de fecha, útil para encontrar registros históricos.
  • Botón "FILTRAR": Aplica los criterios de búsqueda y actualiza la lista de pacientes. FILTRAR
  • Lista de Pacientes: Muestra un resumen de los pacientes que cumplen con los criterios de búsqueda. Al hacer clic en un paciente, se expanden sus exámenes realizados para esa fecha.

Acciones con Exámenes de Pacientes

Desde la lista expandida de un paciente en el panel lateral, puede realizar las siguientes acciones:

  • Imprimir Todo: Genera un reporte consolidado con todos los exámenes del paciente para esa fecha, listo para imprimir. Imprimir Todo
  • Enviar por WhatsApp: Permite enviar el reporte consolidado al número de WhatsApp registrado del paciente. WhatsApp
  • Ver Examen Individual: Para cada examen listado, hay un botón que abre el reporte detallado de ese examen específico en el visor principal.
  • Actualizar Entidad: Para cada examen, un menú desplegable permite asociar o cambiar la entidad de salud a la que pertenece el paciente.

Funcionalidades Avanzadas (Modales)

Consulta por Entidades

Acceso desde el botón ENTIDADES en la barra superior. Esta funcionalidad permite generar reportes y estadísticas basados en rangos de fechas y entidades.

Modal de consulta por entidades con opciones de filtro

  • Filtros:
    • Entidad: Menú desplegable para seleccionar una entidad específica o "Todas las entidades".
    • Fecha Inicio y Fecha Fin: Campos de fecha para definir el período de la consulta.
    • Mostrar solo exámenes con resultados: Casilla para incluir únicamente exámenes que ya tienen resultados registrados.
    • Agrupar resultados por fecha: Casilla para organizar los resultados agrupados por el día de realización.
  • Resultados: Muestra un resumen de la consulta (total de exámenes, total de fechas cubiertas) y una lista detallada de los exámenes agrupados por fecha (si se seleccionó la opción). Cada examen muestra el paciente, identificación, edad, género y el nombre del examen, junto con su resultado y referencia rápida.
  • Acciones: Desde esta modal, puede EXPORTAR a EXCEL los resultados o IMPRIMIR la lista visualizada.

Búsqueda de Pacientes

Acceso desde el botón PACIENTES en la barra superior. Permite realizar búsquedas exhaustivas de pacientes registrados en el sistema, incluyendo sus datos demográficos y un resumen de sus exámenes.

  • Filtros:
    • Identificación: Número de documento del paciente.
    • Nombres Completos: Nombres y apellidos del paciente.
    • Teléfono: Número de contacto del paciente.
    • Ciudad: Ciudad de residencia del paciente.
    • Entidad: Entidad de salud a la que pertenece el paciente.
  • Resultados: Presenta una lista de tarjetas de pacientes coincidentes, mostrando información detallada (nombre completo, identificación, edad, género, contacto, dirección, entidad). Cada tarjeta permite expandir para ver un resumen de sus exámenes con las fechas y códigos.
  • Acciones: Puede EXPORTAR a EXCEL la lista de pacientes encontrados o VER el perfil completo de un paciente individual para cargarlo en el panel principal.

Gestión Interna del Laboratorio

Descripción General de Funcionalidades Administrativas

Esta sección detalla las funciones administrativas y operativas del sistema, accesibles para el personal autorizado del laboratorio. Abarca la gestión de datos de pacientes, resultados de exámenes, configuración del sistema y mantenimiento de procedimientos.

Gestión de Pacientes (Administración)

El sistema permite al personal administrativo buscar y acceder a la información de los pacientes de diversas maneras:

  • Búsqueda General de Pacientes: Permite obtener un listado completo de pacientes o filtrar por criterios específicos (nombre, identificación, etc.).
  • Búsqueda de Pacientes por Fecha: Facilita encontrar pacientes que han tenido exámenes registrados en una fecha particular.
  • Consulta Detallada de Paciente: Accede a toda la información de un paciente utilizando su número de identificación.

Gestión de Exámenes (Resultados y Edición)

Esta funcionalidad es clave para el laboratorio, permitiendo la consulta y gestión de los resultados de los exámenes:

  • Consulta de Exámenes por Paciente: Obtiene un listado de todos los exámenes asociados a un paciente, pudiendo filtrar por fechas.
  • Acceso a Tipos de Examen Específicos: El sistema soporta la recuperación detallada de resultados para diversos tipos de exámenes, incluyendo:
    • Hemogramas (incluyendo versiones Rayto).
    • Uroanálisis (Parcial de Orina).
    • Coprológicos.
    • Frotis Vaginal.
    • Perfiles Lipídicos.
    • Exámenes Genéricos Tipo 1 y Tipo 2 (para resultados simples o específicos).

Guardado y Actualización de Resultados de Exámenes

El personal del laboratorio puede registrar y actualizar los resultados de los exámenes en el sistema:

  • Registro de Resultados por Tipo de Examen: Permite guardar los datos específicos para Hemogramas, Uroanálisis, Coprológicos, Frotis Vaginal, Perfiles Lipídicos y Exámenes Genéricos (Tipo 1 y Tipo 2).
  • Asignación Múltiple de Exámenes: Es posible guardar un conjunto de exámenes asignados a un paciente en una fecha determinada.
  • Actualización de Estado de Examen: El sistema marca un examen como procesado o guardado una vez que sus resultados han sido registrados.

Registro de Pacientes (Aplicación Desktop)

La aplicación Flutter de escritorio permite registrar nuevos pacientes en el sistema. El proceso se realiza a través de la página "Crear Paciente":

  • Acceso: Navegar a la sección dePacientes en el panel decontrols de la aplicación.
  • Formulario de Registro:
    • Identificación: Número de documento único (mínimo 6 dígitos). Este campo es la clave primaria del paciente.
    • Nombres: Nombres completos del paciente (mínimo 3 caracteres).
    • Apellidos: Apellidos completos del paciente (mínimo 5 caracteres).
    • Fecha de Nacimiento: Selector de fecha en formato YYYY-MM-DD.
    • Género: Selector entre Masculino, Femenino u Otro.
    • Teléfono: Número de contacto (mínimo 10 dígitos).
    • Correo: Dirección de correo electrónico válida.
    • Entidad: Entidad de salud a la que pertenece el paciente.
  • Validaciones: El sistema valida automáticamente cada campo antes de permitir el guardado.
  • Edición: Al ingresar una identificación existente, el sistema carga los datos para su actualización.

Endpoint: savePaciente.php - Recibe un objeto JSON con todos los campos del paciente y lo almacena en la base de datos.

Creación de Exámenes para Pacientes

Para registrar exámenes asociados a un paciente, la aplicación permite:

  • Seleccionar Paciente: Ingresar el número de identificación del paciente en el campo de búsqueda.
  • Seleccionar Fecha: Elegir la fecha en que se realizarán los exámenes (por defecto, la fecha actual).
  • Elegir Exámenes: Del catálogo de procedimientos disponibles, seleccionar uno o más exámenes asignados.
  • Confirmar Asignación: Guardar la lista de exámenes asociados al paciente y fecha.

API: guardarExamenes.php - Recibe JSON con identificación, fecha y lista de procedimientos.

El sistema luego permite buscar estos exámenes por fecha o por paciente para registrar sus resultados.

Registro de Resultados de Exámenes

Cada tipo de examen tiene su propio formulario de captura de resultados. El sistema detecta automáticamente el tipo de examen según el código asignado y carga el formulario correspondiente.

Flujo de Registro de Resultados

  1. Buscar Examen: Desde el panel de consulta, buscar el examen asignado al paciente.
  2. Seleccionar Tipo: El sistema carga el formulario correspondiente al tipo de exame.
  3. Completar Resultados: Llenar cada campo con los valores obtenidos del análisis.
  4. Guardar: Guardar los resultados. El sistema automáticamente marca el exame como "procesado".
  5. Imprimir (opcional): Generar el reporte PDF para entregar al paciente.

Importante: Después de guardar los resultados, el sistema llama automáticamente a updateExamen.php para marcar el exame como realizado. Esto actualiza el estado en la lista de exámenes del paciente.

Impresión de Reportes

La generación de informes en formato PDF es una función esencial. El sistema permite:

  • Generación de PDF por Examen: Imprime un reporte detallado de un examen específico de un paciente, incluyendo sus datos demográficos y los resultados.
  • El sistema utiliza una interfaz web para previsualizar y generar estos documentos, garantizando un formato profesional y listo para entregar.

Gestión de Configuración

El sistema ofrece opciones para gestionar su configuración, lo que permite adaptar ciertos parámetros a las necesidades del laboratorio:

  • Recuperación de Configuración: Carga la configuración actual del sistema.
  • Guardado de Configuración: Permite actualizar y almacenar la configuración modificada.

Gestión de Procedimientos y Constantes

Para el control de los servicios ofrecidos, el sistema permite:

  • Consulta de Procedimientos: Obtiene un listado de todos los exámenes y procedimientos disponibles.
  • Consulta Detallada de Procedimiento: Accede a la información específica de un procedimiento (código, nombre, valores de referencia, etc.).
  • Guardado de Procedimientos: Permite añadir nuevos procedimientos o actualizar los existentes.
  • Gestión de Ítems de Exámenes: Administra listas de opciones o valores predefinidos asociados a ciertos campos de exámenes.
  • Consulta de Unidades y Constantes: Proporciona acceso a las unidades de medida y valores constantes asociados a los exámenes.

Eliminación de Exámenes

En casos necesarios, el sistema permite eliminar registros de exámenes:

  • Borrado de Exámenes: Elimina un examen específico asociado a un paciente y una fecha.
